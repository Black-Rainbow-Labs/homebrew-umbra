# Homebrew tap for Umbra

[Umbra](https://github.com/Black-Rainbow-Labs/umbra) is a small coding agent for the terminal and
for editors that speak the Agent Client Protocol.

```sh
brew install black-rainbow-labs/umbra/umbra
```

`Formula/umbra.rb` is written by `packaging/release.ps1` in the Umbra repository for each release,
with the checksums from the release's `SHA256SUMS`.
